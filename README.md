# DSA

This subject folder is the working surface for DSA retention, rebuilds, and interview preparation.

Primary workflow:

- Use NeetCode as the intake surface for course lessons, visual pattern explanations, and curated challenge progression.
- Use this folder as the ownership surface for notes, cold rebuilds, drills, mistakes tracking, extra variants, and interview-style reps.
- Do not duplicate full lesson content here unless a local note is needed to explain a miss or preserve a pattern model you could not reproduce from memory.

Subfolders:

- `Planning/`
- `Drills/`
- `Exercises/`
- `Challenges/`
- `Curriculum/`
- `Repairs/`
- `Useful Links/`

How each folder should be used:

- `Curriculum/` stores concise local notes, pattern summaries, and corrected mental models worth keeping.
- `Challenges/` stores active problem work, cold rebuilds, and multi-problem reps after a NeetCode lesson or challenge block.
- `Exercises/` stores short one-off pattern checks, traces, and contract-first reps.
- `Drills/` stores timed recall and pattern-selection pressure reps.
- `Repairs/` stores targeted fixes for misses exposed by drills, challenges, or interview practice.
- `Planning/` stores trackers, mistakes logs, and the current DSA operating plan.

Operating rule:

- Every studied NeetCode problem should create one artifact here that proves ownership: a cold rebuild, a drill result, a mistake-log entry, a repaired explanation, or an interview-style walkthrough.
